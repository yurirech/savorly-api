[bread.programs]
Choose the program from the dish. Never ask the user which cycle to run. Name it in step 1.

Basic — enriched sandwich, seeds, milk powder, most default loaves.
French — lean dough, crisp crust, little fat or sugar.
Fast — short cycle, mostly white AP. Multiply Basic yeast ×1.25–1.5. Never Fast if wholegrain is heavy (>30% whole wheat).
Knead — pizza, rolls, focaccia, anything shaped by hand after the pan. Then shape, proof, and oven-bake in later steps. Do not tell the user to run a full bake cycle in the machine.

Skip Bake-only unless notes say the dough is already shaped.
