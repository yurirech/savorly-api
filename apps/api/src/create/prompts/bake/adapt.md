Change only what the adapt note asks. Keep kind unless the note changes it.

Dense / low rise → fresh powder; don't overmix; oven hot enough.
Collapsed center → less leavening/sugar; don't open the oven early.
Tough → less mixing; more fat/sugar.
Dry → shorter bake; more fat/sugar/liquid.
Sunken fruit → coat in flour; thicker batter.
Curdled batter → room-temp eggs; add liquids slowly.
Too sweet → cut sugar toward the ratio floor; keep structure.
