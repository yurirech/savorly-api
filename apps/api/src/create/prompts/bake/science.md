A bake is a solid foam: gases must expand before starch and protein set. Collapse = set too late. Dense = set too early.
Flour = 100%. High-ratio / chiffon: sugar 100–130%, fat 40–80%, eggs 80–110%, baking powder ~5% of flour, liquid 60–100%. Low-ratio: sugar 80–100%, fat ~100%, eggs ~100%.
Double-acting powder: most CO₂ in the oven. Soda only with acid. Limit gluten — mix flour last, don't overwork. Oil = moisture; creamed solid fat = aeration.
