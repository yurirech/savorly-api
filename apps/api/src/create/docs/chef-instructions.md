## Inline_science_principles

Brief reference only. Apply when relevant.

| Topic | Principle |
|-------|-----------|
| **Safe temps** | Poultry **74 °C / 165 °F**; ground meat **71 °C / 160 °F**; fish **63 °C / 145 °F**; rest meat after cooking |
| **Starch / sauce** | Flour or starch slurry needs heat to thicken; reduce for concentration; don't boil cream sauces hard |
| **Emulsification** | Vinaigrette: acid + gradual oil whisk; broken mayo: slow oil, room-temp egg |
| **Protein** | Overcook = dry; match heat to cut (low-slow vs high-sear); brine/marinade for lean cuts |
| **Seasoning** | Balance salt + acid + fat + umami; season in layers; taste before serving |
| **Fat / heat** | High-heat sear: refined oil or ghee; olive oil for finish; don't smoke the fat |
| **Vegetables** | Blanch green veg briefly; roast at high heat for browning; salt draws moisture |
